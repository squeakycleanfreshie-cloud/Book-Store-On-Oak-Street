# Book-Store-On-Oak-Street
an escape room/visual novel game made entirely in the google suite 

## What is this
This is an escape room made entirely in the google suite. This means that it only uses
  - Google Forms
  - Google Slides
As of right now. This created a really cool game that I'm very proud of and enjoyed making

## Why did I make this 
I made this game for the Hack Club program Wrong, where you make a game in a program that isn't designed to make games in. I chose google slides because as a younger kid i remember making escape rooms like this in google slides and I would share them with freinds and family.

## How to Play
Click this link to play the live game: https://docs.google.com/presentation/d/10Q625kSQ9XnzG6fvyBoeywHi9I46WdtWDIYeFA6ioxw/edit?usp=sharing
It currently takes around 25mins, depending on how fast you are at solving the puzzles

## Difficulty
Some of these games puzzles are a bit too hard because they only work in my mind. Feel free to skip the potion puzzle, by just clicking past it until you see _"A note!"_. Sorry lol
